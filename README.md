## Projetos

### [Predição de glicose em jejum - NHANES](https://github.com/mrpedroox/fasting-glucose-prediction-nhanes)

Pipeline de Machine Learning desenvolvido com dados públicos do CDC/NHANES de 7.612 participantes. Inclui preparação de dados, engenharia de atributos, validação cruzada e comparação de modelos de regressão.

`Python` `scikit-learn` `pandas` `NumPy` `matplotlib` `seaborn`

### [Certificates PET](https://github.com/mrpedroox/Certificates_PET)

Sistema web para gerenciamento de eventos, participantes e emissão de certificados do PET Computação/UFC. Possui API REST, interface web, persistência em PostgreSQL e ambiente conteinerizado.

`FastAPI` `SQLModel` `PostgreSQL` `React` `JavaScript` `Docker`

### [FIRE](https://github.com/mrpedroox/FIRE)

Solução IoT para detecção de incêndio em tempo real, com sensores conectados a um ESP8266, processamento e persistência na IBM Cloud e aplicativo iOS para monitoramento e alertas.

`Swift` `SwiftUI` `C` `Node-RED` `IBM Cloud` `Cloudant` `ESP8266`

### [ArtGallery](https://github.com/mrpedroox/ArtGallery)

Sistema em Java para curadoria e exposição de arte digital, desenvolvido com foco em Programação Orientada a Objetos.

`Java` `OOP`
