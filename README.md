## Projetos em destaque

### 🩺 [Predição de glicose em jejum — NHANES](https://github.com/mrpedroox/fasting-glucose-prediction-nhanes)

Pipeline de Machine Learning para prever glicose plasmática em jejum a partir de variáveis demográficas e antropométricas não invasivas. O projeto integra dados públicos do CDC/NHANES de **7.612 participantes**, provenientes de três ciclos entre 2015 e 2023.

`Python` `scikit-learn` `pandas` `NumPy` `matplotlib` `seaborn`

- Integração, limpeza, seleção e engenharia de variáveis em quatro conjuntos de dados
- Comparação entre Regressão Linear, Ridge, Random Forest e Gradient Boosting
- Grid Search, validação cruzada com 5 folds e avaliação por MAE e R²
- Documentação dos resultados em formato de artigo acadêmico

### 🎓 [Certificates PET](https://github.com/mrpedroox/Certificates_PET)

Aplicação web desenvolvida em equipe para o **PET Computação/UFC**, voltada ao gerenciamento de eventos, participantes e emissão de certificados.

`FastAPI` `SQLModel` `PostgreSQL` `React` `JavaScript` `Docker`

- API RESTful e persistência de dados com PostgreSQL
- Integração entre frontend, backend e banco de dados
- Ambiente conteinerizado com Docker Compose, persistência e health checks

### 🔥 [FIRE](https://github.com/mrpedroox/FIRE)

Sistema IoT de detecção de incêndio em tempo real, desenvolvido durante o HackaTruck MakerSpace. Monitora temperatura, fumaça e presença de chamas, processa os dados na nuvem e envia alertas ao usuário por uma aplicação iOS.

`Swift` `SwiftUI` `C` `ESP8266` `Node-RED` `IBM Cloud` `Cloudant`

### 🖼️ [ArtGallery](https://github.com/mrpedroox/ArtGallery)
